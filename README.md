## About
This repository contains practical work for Phase 2 of the Sqrock Alpha 2 Cybersecurity Internship. Phase 2 focuses on technical asset analysis, defensive Python scripting, mitigation automation, and secure infrastructure posture assessments.

> **Legal notice:** Execute all curriculum tasks exclusively inside isolated, authorized local lab environments. Do not scan real-world targets or unauthorized infrastructure.

## Folder structure
Each `Day_XX` folder contains a README with the task focus and space to document implementation, testing, results, and deliverables. Add your actual scripts, safe sample data, screenshots, and reports to the relevant folder as you complete each task.

## Safety
- Use localhost, loopback addresses, private lab networks, and intentionally vulnerable practice systems that you own or are explicitly authorized to test.
- Never commit API keys, passwords, tokens, webhook URLs, personal data, or real victim information.
- Use fictional or anonymized sample data in reports and screenshots.
- Clearly label simulated actions; do not claim that simulated firewall blocks, webhooks, or host isolation changed real systems.
